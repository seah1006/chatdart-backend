# ChatDART — Backend

DART(금융감독원 전자공시시스템) 재무제표를 수집·분석하고, 예측 모델과 AI 요약으로 해석해 주는 웹 서비스의 백엔드입니다.
「복잡한 재무제표를 검색 한 번으로」 — 투자 입문자도 기업의 재무 상태를 읽을 수 있게 하는 것이 목표입니다.

> 대학교 3인 팀 프로젝트(2026)의 백엔드 저장소를 공개용으로 정리한 사본입니다.
> 운영 설정·내부 문서·과거 이력은 포함하지 않습니다.

## 팀 구성

| 파트 | 담당 | 저장소 |
|---|---|---|
| **백엔드** | 정세아 (팀장) | 이 저장소 |
| 프론트엔드 | 프론트엔드 담당 | 별도 저장소(비공개) |
| AI (예측 모델) | AI 담당 | [skyhubstk/ai-server](https://github.com/skyhubstk/ai-server) |

## 주요 기능

- **재무 데이터 수집** — 기업명·종목코드로 검색하면 DART OpenAPI 에서 5개년 재무제표를 백그라운드로 수집하고, 진행 상태를 폴링으로 제공
- **지표 분석** — 수익성·안정성·성장성 지표 계산, 업종 평균·순위 비교, 기업 간 비교
- **금융업 분기** — 은행·금융지주는 계정 체계가 달라 별도 매핑과 공통 지표만 제공
- **예측 · AI 해석** — LightGBM 모델로 다음 해 영업이익(금융업은 당기순이익)을 예측하고, OpenAI 로 3줄 요약·핵심 신호 해석 생성
- **회원 · 멤버십** — JWT 인증, 관심 종목, 공지, 관리자 기능
- **PDF 내보내기 · 상장폐지 판별**(한국거래소 공식 API)

REST API 65개 엔드포인트(라우터 6개). 실행 후 `/docs`(Swagger)에서 전체 목록을 볼 수 있습니다.

## 설계에서 신경 쓴 것

### AI 응답을 그대로 믿지 않는다 — 서버 검증

AI 에게 정답 숫자를 넘겨도 표현을 바꾸거나 다른 내용을 섞는 경우가 있었습니다. 그래서

1. 서버가 예측 연도·금액·단위가 들어간 **표시 문구를 결정적으로 생성**하고 (`build_prediction_display_text`)
2. AI 가 쓴 요약이 그 문구를 지켰는지 **서버가 검사**해서
3. 통과한 요약만 내보내고, 통과하지 못하면 AI 문단을 빼고 서버가 만든 예측 문장으로 대신합니다.

이 구조와 문안 개선으로 **AI 요약 채택률(검사를 통과해 그대로 쓰인 비율)이 60% → 86.7%** 가 됐습니다.
<sub>2026-09-16 운영 환경 측정, 적용 전후 각 15회 생성 표본 — 표본이 작다는 한계가 있습니다.</sub>

### 파트 사이의 약속을 테스트로 고정

세 파트가 다른 저장소에서 개발했기 때문에, 프론트가 기대하는 응답 형식이나 AI 담당이 확정한 문안처럼 **파트가 만나는 지점**을 자동 테스트로 고정했습니다.
일부러 코드를 망가뜨려 테스트가 실제로 잡아내는지도(변이 검증) 확인했습니다.

### 예측 모델은 단순 기준선과 비교해 정직하게 평가

연도 기준으로 다시 검증한 결과, 현재 모델이 「전년도 값을 그대로 쓰는」 단순 기준선을 확실히 이긴다고 말할 수 없었습니다. 이 결과를 숨기지 않고 다음 개선 과제로 두었습니다.

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| API | FastAPI, Pydantic, SlowAPI(요청 한도) |
| DB | SQLAlchemy, Alembic, PostgreSQL(운영) / SQLite(개발·테스트) |
| 외부 연동 | DART OpenAPI(dart-fss), 한국거래소 API, OpenAI |
| 예측 | LightGBM, scikit-learn, pandas |
| 운영 | Docker, AWS EC2 + RDS, GitHub Actions CI(Python 3.11) |

## 실행

```bash
pip install -r requirements.txt
cp .env.example .env          # DART_API_KEY · API_SECRET_KEY · JWT_SECRET_KEY 필수
uvicorn app.main:app --reload # http://localhost:8000/docs
```

시크릿 생성: `python -c "import secrets; print(secrets.token_hex(32))"`

예측 모델 파일(`models/*.pkl`)은 AI 파트 산출물이라 이 저장소에 포함하지 않았습니다. 모델 파일이 없으면 예측 엔드포인트는 503 을 반환하고, 나머지 기능은 그대로 동작합니다.
