# 개발 방식 — 과정 문서 샘플

이 저장소는 이력 없는 공개용 사본이라 커밋 기록으로는 작업 과정이 보이지 않습니다.
대신 원본 저장소에서 실제로 쓴 과정 문서 한 세트를 **수정 없이** 옮겨 왔습니다.

## 구조

2026년 5월부터 AI 코딩 에이전트로 개발했습니다. 에이전트끼리는 대화하지 않고 **저장소의 문서로만** 일을 주고받습니다.

| 단계 | 담당 | 산출물 |
|---|---|---|
| 1. 계획 | Claude | 작업 지시서(Work Packet) — 범위·제약·검증 방법·변이 목록 |
| 2. 구현 | Codex | 구현 보고서(Handoff) — 요구사항마다 실행 명령과 출력을 적은 증거표 |
| 3. 리뷰 | 독립 리뷰 세션 | 리뷰 문서 — Critical / Major / Minor 판정. 계획한 세션은 스스로 승인하지 않음 |
| 결정 | 팀장(백엔드 담당) | 범위·우선순위, 배포·운영 접속·과금 호출 승인, 다른 파트와의 계약 |

규칙 전문: [`agent_protocol.md`](agent_protocol.md)
